# Работа с метафорични карти

React + Vite + TypeScript приложение на български по части II–V от „Работа с метафорични карти“ на Яна Аврамова.

## Стартиране

```sh
npm install
npm run dev
```

```sh
npm run build
npm run preview
```

## Съдържание и поведение

21 основни упражнения: 7 самостоятелни, 3 по двойки, 7 групови и 4 детски. Отделни адаптации за двойки, групи и деца са достъпни чрез филтъра в библиотеката. Използват се предоставените 55 изображения, без интерпретации или предварително зададени значения.

Упражненията включват визуален избор, скрито теглене без повторение, пространствен мост, свободно подреждане с координати, турнирно редуциране, зависима верига от отговори, авторски диалог, последователно разказване, размяна с двустранно съгласие, ротация на думи, скрити ръце, заключени предположения, групиране и рисуване около карта.

Груповите упражнения са за водещ и работа на едно устройство с общуване на живо. Личните избори използват изрично отваряне/затваряне на личния изглед; това не е защита срещу друг човек с достъп до устройството. Няма синхронизация между устройства или онлайн мултиплейър.

Данните се пазят в localStorage на текущия браузър. Черновите се възстановяват автоматично, завършените записки се запазват изрично и могат да се експортират като JSON. За повече от 18 участници в „Пазар на ценности“ е необходима допълнителна колода; интерфейсът ограничава броя до наличните карти.

## Структура

- `src/data.ts`: каталог, адаптации, метаданни, разбъркване на колода.
- `src/main.tsx`: маршрути, работни пространства, персистентност и интерактивни компоненти.
- `src/style.css`: адаптивен дизайн.
- `public/cards`: оригиналните изображения.

Съдържанието е сверено с печатни страници 49–104 на предоставената книга. Времетраенето е ориентировъчно. Приложението не генерира отговори от името на картите.
